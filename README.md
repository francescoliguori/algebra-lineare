# Algebra lineare · esercizi

Le dispense, gli esercizi con correzione automatica e la simulazione d'esame del corso di Algebra Lineare e Matematica Discreta.

**Apri la pagina:** https://francescoliguori.github.io/algebra-lineare/

Sul telefono si può installare come app: dal menu del browser scegli «Aggiungi a schermata Home».

A cura di Francesco Salvatore Liguori  
Università della Calabria  
Dipartimento di Ingegneria Informatica, Modellistica, Elettronica e Sistemistica (DIMES)

## Segnalare un errore

In fondo a ogni esercizio c'è il link «Segnala un errore in questo esercizio»: apre una segnalazione con l'esercizio già indicato. Serve un account GitHub (gratuito). Le segnalazioni sono pubbliche: non scrivere dati personali.
